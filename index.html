Browser Proxy (fallback)

The Browser tab fetches pages through a proxy so sites that block being embedded still load. Public proxies are tried automatically, but they are unreliable. For a proxy that always works, deploy the included Cloudflare Worker — it is free, needs no install, and works on any device (including Chromebooks).

Deploy it in about 2 minutes, all in your browser:

1. Sign in at dash.cloudflare.com (free).
2. Go to Workers & Pages → Create → Create Worker.
3. Delete the sample code, paste the contents of proxy/worker.js, then click Deploy.
4. Copy your worker URL (e.g. https://mist-proxy.you.workers.dev) and paste it below.

Enter it as https://your-worker.workers.dev/?url=, or use %s as the placeholder for the target URL. Leave it empty to use the public proxies. On a PC you can instead run the bundled proxy with cd proxy && dotnet run and enter http://localhost:8787/?url=.
